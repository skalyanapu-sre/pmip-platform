# Architecture Decision Records

Architecture Decision Records (ADRs) document significant technical and architectural
decisions made for PMIP.

Each ADR should explain:

1. Context
2. Problem
3. Decision
4. Alternatives considered
5. Consequences
6. Security implications
7. Operational implications

Naming convention:

0001-use-azure-databricks.md
0002-use-unity-catalog.md
0003-use-managed-identity-for-adls.md
0004-use-github-oidc.md
0005-use-databricks-bundles.md

ADRs should be treated as immutable historical records after acceptance.
If a decision changes, create a new ADR that supersedes the previous one.
