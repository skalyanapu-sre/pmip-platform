# PMIP Operational Runbooks

Runbooks document repeatable operational procedures for PMIP.

Planned runbooks include:

- Databricks pipeline failure
- Databricks job failure
- Airflow DAG failure
- Data quality failure
- ADLS access failure
- Unity Catalog permission failure
- API outage
- MCP service failure
- AKS pod failure
- High CPU or memory utilization
- Secret rotation
- Terraform deployment failure
- Disaster recovery
- Production rollback
